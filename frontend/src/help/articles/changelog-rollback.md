category: Change log and admin export

---

Each change-log row has a **Rollback** action that returns that booking to the
state it was in before the change.

If a booking is already at the state you are rolling back to, you will see
*Booking is already at the resolved rollback state* — nothing to do.

Rollback works one booking at a time. To unwind a whole session, restore from a
[backup](#export-backup-restore) instead.
