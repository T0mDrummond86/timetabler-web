A **group** is one cohort of students — the thing that gets a column on the
timetable grid. Group codes usually read like `BFF7 CIII IT GrpA`.

Groups are created for you when you set a qualification's **Number of groups**:
asking for three groups gives you `GrpA`, `GrpB` and `GrpC`. That is the normal
way to make them.

On the **Groups** editor you can rename a group, change its code, or set
*timetable locked* to protect its whole week from being rebuilt.

A group code must be unique in the session. *A course called 'X' already
exists* means that code is taken.
