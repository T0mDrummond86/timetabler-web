Three copy actions sit on the Change log tab:

- **Copy all listed changes** — the whole list, formatted for email.
- **Copy the active changes as a table naming every lecturer each change
  affects** — use this when you need to tell each lecturer what moved.
- **Copy this change** — a single row.

All three produce a table you can paste directly into an email.

There is also a **Change log** report in the **Export ▾** menu, which downloads
the resolved net changes as a file.
