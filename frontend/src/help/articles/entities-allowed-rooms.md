On the **Classes** tab, a class can carry a list of **allowed rooms**. Booking
it into any other room raises
[Room not on allowed list](#warnings-room-not-allowed).

An **empty list means no restriction** — the class can go anywhere. Only add
rooms when the class genuinely needs specific ones, such as a lab or a
workshop.
