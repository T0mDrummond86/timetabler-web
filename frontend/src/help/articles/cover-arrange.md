The **Lecturer cover** tab builds a cover plan for one week.

![The Week beginning date box on the Lecturer cover tab](/help/cover-week-beginning.png)

1. Set **Week beginning** — the **Monday** of the week being covered. Every
   request is dated from it, so a class on the Wednesday is automatically dated
   to that Wednesday.
2. Choose the **Lecturer requiring cover**. Their classes for the week appear.
3. For each class that needs covering, pick a **Cover lecturer**.

Each pending request shows the class, group, day and time, plus the cover
lecturer's **Hours owed** and **Owed after cover** — see
[Hours owed](#cover-hours-owed).

Leave a row as *Unassigned…* to skip it.
