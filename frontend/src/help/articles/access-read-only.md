category: Account and security

If you have **read-only** access to a session you can look at everything but
change nothing. You will see messages like *Read-only access — you cannot make
changes to this session*, and imports are disabled.

Access is granted per session on its **Settings** page, under *Who can edit this
session*, and per workspace on the **Access** tab of the global workspace.

Levels are **Always edit**, **Read-only**, and **Group default** — which follows
whatever the workspace grants.

Whoever created a session always keeps edit access to it.
