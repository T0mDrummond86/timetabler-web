title: Link sessions into a workspace
category: Global workspace
keywords: link session, add session to global, linked sessions, join workspace, members, connect sessions
---

The **Linked sessions** tab of a global workspace lists its member sessions and
lets you add more.

Once linked, a session's lecturers are matched by name with the others, so a
lecturer teaching in two sessions is understood to be one person.

Sessions must belong to the same organisation — *Both sessions must belong to
the same global group* means one of them is somewhere else.

**Update from linked sessions** pulls the latest from the members when the
aggregate looks stale.
