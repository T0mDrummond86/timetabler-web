category: Block delivery and variants

Most sessions run the same week every week. When some weeks differ, turn on
*Alternate schedules in some weeks* and use the variant bar above the grid to
switch between them.

The bar shows **Regular** plus any variants you have defined. Editing the grid
while a variant is selected changes that variant only.

The semester panel shows which weeks are **Teaching day** or **Non-teaching
day**, and lets you set an **Override for this session** where a week differs
from the workspace calendar. *No override* means it follows the calendar.
