A **class** is the thing you place on the timetable. Open the **Classes** tab
to manage them.

Select a class from the list to edit:

- **Class name** — what shows on the placecard.
- **Units** — the unit codes this class delivers. One class often covers
  several units clustered together.
- **Duration** — how long the class runs. Every placecard for the class uses
  this length.
- **Qualifications** — which qualifications the class belongs to. A class can
  belong to more than one.
- **Allowed rooms** and **allowed lecturers** — see
  [Restricting rooms](#entities-allowed-rooms) and
  [Allowed lecturers](#staff-competency).

**New class** creates one. A class name is required.
