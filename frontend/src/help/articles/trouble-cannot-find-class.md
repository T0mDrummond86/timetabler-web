id: trouble-cannot-find-class
title: A class is missing from the holding area
category: Troubleshooting
keywords: cannot find class, missing class, not in holding area, where is my class, class disappeared, not showing
---

The holding area only lists unscheduled classes **for the groups currently
selected in the sidebar**. A missing class is usually one of:

- **It is already scheduled.** It is on the grid somewhere, so it has left the
  holding area.
- **Its group is not selected.** Widen the sidebar selection.
- **It is not linked to this qualification.** Check the class's qualifications
  on the **Classes** tab.
- **It does not exist yet.** Create it, or bring it in with an
  [import](#import-which-one).

*Class already fully scheduled* when you try to place it means every group's
copy of that class is already on the grid.
