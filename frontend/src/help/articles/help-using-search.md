Type what is going wrong, in your own words. The search understands meaning
rather than matching words exactly, so *"two lecturers in one room at the same
time"* finds
[Room double-booking](#warnings-room-double) even though it shares no wording
with the title.

Describing the symptom works better than guessing the feature name. *"get my
spreadsheet back into the app"*, *"students are in two places"*, *"stop asking
me for a code"* all land where you would hope.

The first search after opening Help takes a moment while the language model
loads. After that it is instant, and it keeps working offline.

Everything runs on your own machine — nothing you type here is sent anywhere.
