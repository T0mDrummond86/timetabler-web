**Import ▾** on the timetable toolbar offers:

![The Import menu, listing Session backup, Qualifications CSP, EP-NB CSP and aSc export](/help/toolbar-import.png)

- **Session backup** — a full round-trip restore from a previous export
  (`.xlsm` / `.xlsx`). See [Backup and restore](#export-backup-restore).
- **Qualifications template** — classes and qualifications from the
  QInputTemplate workbook.
- **Qualifications CSP** — a **course study plan** in Word format (`.docx`).
  See [Importing a CSP](#import-csp).
- **EP-NB CSP** — the East Perth / Northbridge course study plan spreadsheet
  (`.xlsx`). See [Importing an EP-NB CSP](#import-ep-nb-csp).
- **aSc export** — staff, rooms, classes, qualifications and bookings from aSc
  Timetables (`.xlsx` or `.xml`). See [Importing from aSc](#import-asc).
- **Lecturer preferences** — availability and competency spreadsheet. See
  [Lecturer preferences](#import-lecturer-preferences).
- **Overall visual grid** — the legacy Joondalup *Overall* sheet.
- **Admin export (visual grid)** — course tabs with week bands. **This replaces
  bookings**, so treat it as a restore rather than a top-up.

Importing is disabled if you have read-only access.
