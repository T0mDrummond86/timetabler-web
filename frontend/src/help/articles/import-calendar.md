The term calendar sets which weeks are teaching weeks and which are not.

Import it from the **global workspace**, on the **Calendar** tab, with **Import
calendar CSV**. Each week is marked as a **Teaching day** or a
**Non-teaching day**.

The calendar feeds the week bands in the
[admin export](#changelog-admin-export-red) and the week grid used by
[block delivery](#block-delivery).

*Calendar import failed* usually means the CSV columns are not what the importer
expects — start from a previously exported calendar if in doubt.
