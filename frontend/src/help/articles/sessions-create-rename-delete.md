title: Create, rename, duplicate or delete a session
category: Getting started
keywords: new session, create session, rename, duplicate, copy session, delete session, remove, danger zone
---

All four live on the **Dashboard**.

**Create** — type a name into *New session name* and press **New session**. The
session starts empty; bring data in with [an import](#import-which-one).

**Rename** — open the session, go to **Settings**, and use *Rename this
session*.

**Duplicate** — Settings → *Duplicate this session*. Give the copy a name under
*Name for the copy* and press **Save copy**. The copy is a full, independent
snapshot: bookings, entities, settings and all. This is the safe way to try
something risky.

**Delete** — Settings → *Danger zone* → **Delete session**. This cannot be
undone, so duplicate first if you are unsure.

Session names must be unique. If you see *Session 'X' already exists*, pick a
different name.
