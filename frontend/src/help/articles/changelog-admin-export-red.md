The **Admin export** is a term-week grid for administrators. Anything that has
changed since the log was last cleared is **marked in red**, so the person
receiving it can see at a glance what moved.

Two variants sit in the **Export ▾** menu:

- **Admin export** — every course.
- **Admin export (changes only)** — only courses with logged changes.

If nothing is marked red when you expect it to be, check the **Change log** tab
actually has entries for those bookings. Markup is driven by the log, so a
session whose log has been cleared exports clean.

You can remove a single change from the markup while keeping it in the log —
the *Remove a change from the admin-export markup while keeping it logged*
action on that row.
