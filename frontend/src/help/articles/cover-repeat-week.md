title: Repeat a cover request into the next week
category: Lecturer cover

When one class needs covering for more than a week, you do not have to build
the request again.

Each pending request has its own **Repeat next week** button, beside *Push to
log* and *Delete*. It copies **that one request** forward by seven days, keeping
the same class, group, time and cover lecturer.

Press it on the copy to go a week further, and so on — three presses walking
down the list gives you three consecutive weeks of that class.

Because it acts on a single row, classes in the same week can run for different
lengths: cover one class for three weeks and another for one, without creating
rows you then have to delete.

Two things worth knowing:

- A request needs a **cover date** before it can be repeated. Without one there
  is no next week to copy it to, and the button stays disabled.
- Pressing it twice on the same request does nothing the second time. If that
  class is already covered on that date, the existing request stands rather
  than a duplicate being stacked on top.
