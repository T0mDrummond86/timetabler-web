title: Remember this device
category: Account and security
keywords: remember device, trusted device, stop asking, every time, code every login, trust browser, 30 days
---

The sign-in screen offers **remember this device**. Tick it on a computer only
you use and you will not be asked for a code again on that browser for **30
days**.

Do not tick it on a shared or public computer.

The trust is per browser: a different browser, a private window, or clearing
site data all ask for a code again.
