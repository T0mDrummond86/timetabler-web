The grid shows one week: **Monday to Friday** across the top, time down the
left.

Time runs in **30-minute slots** starting at **08:00**. Two slots make an hour,
so a placecard covering four slots is a two-hour class.

Each column is a **group** (a course cohort). Which columns you see depends on
what you picked in the sidebar on the left — a set of groups, a lecturer, or a
room.

Coloured blocks on the grid are **placecards**: one scheduled class, in one
group, at one time.
