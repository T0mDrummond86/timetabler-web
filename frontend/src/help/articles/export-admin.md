**Export ▾ → Admin export** produces the term-week grid administrators expect,
with changes since the last cleared log
[marked in red](#changelog-admin-export-red).

**Admin export (changes only)** narrows it to courses that actually have logged
changes, which is the one to send mid-semester.

The matching **Import ▾ → Admin export (visual grid)** reads the same shape back
in — but note it **replaces bookings**, so only use it to restore.
