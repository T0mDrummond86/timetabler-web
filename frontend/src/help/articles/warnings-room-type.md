title: "Wrong room type"
category: Warnings and clashes
keywords: room type, wrong type, lab required, workshop, needs a lab, type mismatch
---

**Hard clash.** The room's type does not match what the class requires — a class
needing a lab booked into a general classroom, for instance.

Set the room's type on the **Rooms** tab and the class's requirement on the
**Classes** tab, then move the class into a room of the right type.
