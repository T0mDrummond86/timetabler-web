Administrators get an **Administration** area on the Dashboard.

- **Create user** — a display name and username. Usernames are 3–80 characters,
  lowercase letters, digits and `. _ -`. The account is given a generated
  four-word passphrase, shown once — pass it on, and the user must change it at
  first sign-in.
- **Reset password** — issues a new generated passphrase the same way.
- **Clear their two-factor so they can set it up on a new phone** — the fix for
  a user who has lost their phone and their
  [recovery codes](#account-recovery-codes).
- **Disable** / **Enable** — a disabled account cannot sign in at all.

*Username already taken* means that username exists. Self-registration is
switched off; accounts are created here.

Accounts are for people doing timetabling work. Lecturers are not given
accounts — they receive printouts, emails and cover requests instead. See
[Who TAFEtabler is for](#who-the-app-is-for).
