title: My changes are not showing in red in the admin export
category: Troubleshooting
keywords: not red, no markup, changes missing, admin export blank, red not showing, markup missing, changes not marked
---

The red markup comes from the **change log**, not from the bookings themselves.

Check:

1. **The Change log tab has entries** for the bookings you expect. No entries,
   no markup.
2. **The change was not removed from the markup.** Individual rows can be
   excluded while staying in the log — look for that on the row.
3. **You are looking at the right export.** *Admin export (changes only)*
   includes just the courses with logged changes; the plain *Admin export*
   includes everything, with the changed cells in red.
4. **The log has not been cleared.** A session whose log is empty exports clean.
